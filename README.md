# بايثون أكاديمي — Python Academy · CSC 605

**النشر الحي:** https://turkihanan1-arch.github.io/python-academy-605/

نشرة المقرر ومنصة التدريب في نشر واحد:

- **الجذر `/`** — «نشرة المقرر»: صفحة تعريفية بهوية المكتب الورقي، ملف واحد ثابت (HTML/CSS/JS بلا بناء)، محرك scrollcraft، وكل رسم SVG يدوي وكل لقطة حقيقية من المنصة.
- **`/app/`** — منصة التدريب: React + TypeScript + Vite، 36 درسًا بشرح عربي، 16 تحديًا يصحح نفسه، وبايثون حقيقية داخل المتصفح (Pyodide).

الرحلة: النشرة تقنع، وكل روابطها تفتح المنصة مع `?from=prospectus`، وزر «العودة إلى نشرة المقرر» في المنصة يعود إلى الجذر.

## النشر

مستودع ثابت يُقدَّم كما هو (GitHub Pages). تحديث أي جزء:

1. عدّل النشرة في `index.html` أو الهوية في `engine/theme-paper.css` مباشرة.
2. لتحديث المنصة: بنِ التطبيق من مستودع التطوير مع `VITE_PROSPECTUS_URL=../` ثم انسخ المخرجات إلى `app/`.

> المصدر الكامل للتطوير (التطبيق + أدوات الفحص + سجل الهوية) في مستودع العمل المحلي، وهذا المستودع هو حزمة النشر المشتقة منه.
